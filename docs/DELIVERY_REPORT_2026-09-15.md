## 多卡任务与模型测试页面

训练启动时可选择显卡，模型测试也可单独选择一张卡。自动调度会使用空闲设备，显式选择忙卡的任务继续等待，后面使用其他空闲卡的任务仍可启动。每个 CUDA/DTK 进程只看到自己的分配设备，暂停或取消按任务处理，进程真正退出后才释放显卡。

主导航、页面标题、相关入口、任务类型和新建任务默认名称统一为“模型测试”。选择来源训练任务及已保存权重后，可在另一张卡生成测试图；来源训练不必结束。原版本结果和任务详情入口统一跳到这个页面并保留上下文。X/Y/Z 参数轴和已有记录的自定义名称保留，API 路径不变。使用示例、旧并行上限的处理和 API 见 [按显卡运行任务](GPU_JOB_SCHEDULING.md)。

独立复查还修复了旧任务换卡恢复时的随机状态映射、选卡探测期间请求改变的竞态，以及归档项目的任务创建门禁。归档仍保留历史结果与产物查看。

## 海光实机状态与未完成项

正式权重、具体条件与报告散列见 [海光验收记录](DTK_ACCEPTANCE_2026-09-14.md)。Krea2 的单卡/双卡注意力矩阵和运行时 FP8 已有严格通过证据，Klein 也已完成正式单卡、双卡 LoKr 的严格恢复。Anima 与 SDXL 虽能完成训练和恢复执行，但当前正式对照未达到逐位一致，仍是未解决项。

新增的 `loop.deterministic` 默认关闭。DTK 上显式开启时限制 native SDPA 为数学实现；Anima 正式单卡已实测该策略，但严格恢复仍失败，840 个权重张量最大绝对差约 `4.78519e-4`。它不是已经验证有效的修复，也不能承诺显存与速度不变。

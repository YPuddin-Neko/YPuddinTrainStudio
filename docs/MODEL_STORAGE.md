# 模型存放目录

默认位置是项目根目录的 `studio_data/models/`，可在设置的存储路径中修改。模型按组件分类，再按模型系列存放：

```text
models/
├── diffusion_models/
│   ├── anima/
│   ├── krea2/
│   ├── sdxl/
│   └── flux2/
├── vae/
│   ├── shared/       Anima 与 Krea2 共用的 Qwen Image VAE
│   ├── sdxl/
│   └── flux2/
└── text_encoders/
    ├── anima/
    ├── sdxl/
    ├── flux2/
    └── shared/       多个模型使用的文本编码器
```

下载器按此分类保存文件，并在系列目录内用资源标识建立子目录，避免不同来源的同名权重互相覆盖。Anima 与 Krea2 的 VAE 下载共用 `vae/shared/`。已登记、校验一致的推荐权重可直接复用。

完整 Diffusers 模型包放在 `diffusion_models/<系列>/` 下，保留其内部的 VAE、文本编码器、词表和配置结构；不要拆开包内组件，否则模型目录加载会失效。独立组件按上面的类别存放。

训练参数未填写路径时，“浏览”从相应的组件类别目录打开，已有路径则仍从该路径打开。扫描递归读取模型目录，通过配置和权重结构识别组件，不根据文件夹名称判断兼容性。共用 VAE 会显示在其兼容系列的已登记模型选项中。Krea2 Raw/Turbo 无法仅靠权重形状区分时，需要在登记时确认用途。

旧的已登记路径不会被下载器自动搬动或覆盖。测试应复用此模型库，只把测试输出、检查点与缓存写入 `Test/`；下载日志与验收报告也不放入模型目录。

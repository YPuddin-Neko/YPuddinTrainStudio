# 数据集管理

训练数据页按处理顺序分为：数据集管理、数据集检查、数据集筛选、数据集预处理、图片打标、标签编辑、正则数据集。旧链接中的 `data_step=paint` 打开数据集预处理。

## 项目与版本

每个版本独立保存训练配置和数据来源。导入图片时创建版本内副本；新建版本可复制数据，或仅继承参数。直接引用外部目录的来源使用原文件。

打开一个数据集后可修改“文件夹名称”和“每轮重复次数”。重复次数默认 1，用于控制图片在每轮中的出现次数，不生成图片副本。导入时目录名以 `5_` 等数字开头，“导入选项”下会出现“目录名检测到重复 5 次，应用”，点击后才采用该次数。

## 图片与标签导入

上传文件、文件夹或 ZIP 时，单次最多 2 GiB、5,000 个文件。浏览器分块上传，入口限制单个请求大小时会自动减小分块。进度先显示上传字节数，再显示服务端校验与导入进度；所有文件接收并校验完成后才加入数据集。

图片与标签使用相同的主文件名：

```text
images/
├── portrait.png
├── portrait.txt
├── portrait.json
└── portrait.mask.png
```

标签格式设为 `auto` 时优先使用 JSON，其次使用 TXT。显式选择某种格式后只读取该格式。JSON 解析错误会显示具体原因，不能通过同名 TXT 自动回退。

图片按 EXIF 方向校正后参与尺寸计算。导入和索引不自动把原图缩放为训练尺寸。

## 从图站下载

训练集导入和正则采集支持 Danbooru、Gelbooru、e621 和 Rule34。新建导入会生成数据集；在数据集内“添加图片”则追加到当前目录。检索、标签联想和图片下载均使用系统设置中的代理。

| 站点 | 访问凭据 | 分级 |
| --- | --- | --- |
| Danbooru | 可匿名访问；账号等级决定检索标签上限 | 全年龄、敏感、较露骨、露骨 |
| Gelbooru | 用户 ID 和 API Key | 全年龄、敏感、较露骨、露骨 |
| e621 | 可匿名访问，也可填写用户名和 API Key | 全年龄、较露骨、露骨 |
| Rule34 | 用户 ID 和 API Key | 全年龄、较露骨、露骨 |

站点凭据在“设置 → 访问密钥”保存，只发送到对应站点的 API，不发送到图片 CDN。正则采集只查询全年龄图；训练集下载按所选分级检索并再次检查返回的分级。未知分级、动图、无原图地址或不支持的文件格式会跳过。选择全年龄以外的分级时，带 loli、shota 等未成年相关标签的图片不会下载。

e621 和 Rule34 的 Safe、Questionable、Explicit 在界面中显示为“全年龄”“较露骨”“露骨”；e621 的 Safe 不是 Danbooru 的“敏感”（Sensitive）。Rule34 需要 API 密钥才能检索，站点未提供匹配总数时显示未知。请求限速、429 重试、取消、同版本去重与已有下载方式相同；e621 持续请求限制为每秒一次。

## 数据集筛选

从当前版本的训练数据页进入“数据集筛选”。该页面按目录显示“参与训练”和“暂不训练”两栏，支持搜索、预览、多选及批量加入或移出训练。

移出训练只更改参与状态。图片、TXT / JSON 标签和遮罩保留在原目录，再次加入时沿用原文件。筛选操作不等同于删除文件或划分验证集。

目录名称、重复次数、标签和遮罩分别在对应管理页面编辑。验证集通过训练参数中的验证数据设置配置。

## 数据集检查

“数据集检查”读取图片、标签和遮罩，列出无法解码的图片、重复内容、缺少或损坏的标签、尺寸及透明信息等问题。图片、对应标签、遮罩或影响检查结果的设置发生变化时，会提示重新检查，并保留上次报告和检查时间。切换页面、修改无关文件或仅改变文件时间戳，不会使结果失效。

检查结果顶部用六张统计卡片显示图像文件、错误、提示、重复图、遮罩和透明像素。点击卡片会筛选下面的图片；检查页只读，不负责修改训练参与状态。训练图片的加入和移出统一在“数据集筛选”完成。

“重复图”按图片文件内容计算哈希，同一组字节完全一致的文件才会归为一组；文件名、目录或尺寸不同但内容相同仍会被识别，画面相似但内容不同的图片不会被当作重复。

透明信息分为两类：

- **存在 Alpha 通道或透明标记**：文件格式携带透明信息，像素可能仍全部不透明。
- **存在透明像素**：至少一个像素的 Alpha 小于 255，包括半透明像素。

全不透明 RGBA 转为 RGB 后画面不变，可直接用于 LoRA / LoKr 训练。PNG 的色键和调色板透明信息也会参与透明检查。

## 数据集预处理

“自动遮罩”找出图片中不该参与训练的区域，确认后写入遮罩。“遮罩内容”目前可选“头部”，由 Anime Head Detector v2.0-s（deepghs，MIT）检测。

| 参数 | 默认值 | 作用 |
| --- | --- | --- |
| 置信度 | 0.413 | 低于该值的检测框被忽略 |
| 扩展比例 | 0.10 | 检测框向外扩大的比例，覆盖头发与头饰 |
| 羽化比例 | 0.03 | 框外渐变的宽度，0 为硬边 |

点“开始检测”后不会改动任何文件，检测结果逐张列出，每个头部画成一个框：

- 点击框可取消这个头部（例如误检到的海报或玩偶），再点一次恢复；取消勾选图片则整张不写入。
- 点击图片放大查看，可用左右方向键切换图片；“未检测到”列出没有找到头部或无法读取的图片。
- “写入遮罩”只写入仍选中的头部；检测之后图片文件有改动的会跳过，并在结果里说明。
- “重新检测”按当前参数再检测一次，“放弃检测结果”则不写入任何遮罩。

已有遮罩会保留：头部区域与现有遮罩取较小值写回 `.mask.png`；没有独立遮罩的图片以透明信息为基础。没有新增区域的图片不改写。写入后可一次撤销本次写入的全部遮罩。

下方图片列表的预览可叠加显示遮罩，红色区域不参与训练；逐图修改在“打开涂抹与遮罩编辑器”中进行。遮罩只在开启“遮罩加权训练”后生效。

## 图片打标

“Tagger 模型打标”用本地模型识别画面内容和角色，输出 Danbooru 标签。先选系列，再选版本，同一系列新版本在前：

| 系列 | 版本 | 下载大小 | 推荐阈值（通用 / 角色） | 说明 |
| --- | --- | --- | --- | --- |
| WD | EVA02 2026 Canary | 1.3 GB | 0.35 / 0.85 | EVA02-Large 的 2026 增量版，标签更新；作者未声明许可 |
| WD | EVA02-Large v3 | 1.3 GB | 0.35 / 0.85 | 推荐 |
| WD | ViT-Large v3 | 1.3 GB | 0.35 / 0.85 | |
| WD | SwinV2 v3 | 468 MB | 0.35 / 0.85 | |
| WD | ConvNeXt v3 | 395 MB | 0.35 / 0.85 | |
| WD | ViT v3 | 379 MB | 0.35 / 0.85 | |
| WD | MOAT v2 | 326 MB | 0.35 / 0.85 | 体积最小 |
| PixAI | v1.0 | 2.0 GB | 0.17 / 0.27 | 作品 0.24、画师 0.15、元信息 0.17、评级 0.41 使用模型自带阈值 |
| PixAI | v0.9 | 1.3 GB | 0.3 / 0.85 | 只有通用和角色标签 |
| CL Tagger | v2.01a | 2.2 GB | 0.55 / 0.55 | 需要 Hugging Face 访问令牌，并先在模型页同意作者条款 |
| CL Tagger | v1.02 | 1.4 GB | 0.55 / 0.55 | |

各模型按自己的方式读取图片（输入尺寸、缩放、通道顺序和数值范围），结果与 PurinBox 工具箱一致。

- **阈值**：切换模型时换成该模型的推荐值。通用阈值用于通用、元信息和生成模型标签，角色阈值用于角色、作品和画师标签；评级和质量只写把握最大的一个。
- **写入类别**：默认写入通用和角色标签，可加选模型提供的作品、画师、元信息、生成模型、质量和评级。
- **顺序**：人数标签、角色、作品、画师（Anima 项目的画师名前加 `@`）、其余通用标签（按把握从高到低）、元信息、生成模型、质量、评级。默认将下划线转为空格，颜文字保持原样。
- **标签格式**：默认把下划线转换为空格；关闭后保留站点原始写法。开启“括号转义”会把 `(`、`)` 写成 `\(`、`\)`，适合需要把括号当作普通标签字符的训练格式。
- **已有标签**：可跳过已有标签的图片（默认）、追加到后面、添加到前面或覆盖。已存在的标签不会重复添加。
- **触发词**：TXT 写在标签最前面，JSON 写入 `meta.trigger`。
- **排除标签**：列出的标签不会写入，比较时不区分大小写。

打标范围可选全部训练集或单个数据集，暂不训练的图片会跳过。三个打标入口都提供独立的“输出格式”：

| 输出格式 | 生成文件 | 标签结构 |
| --- | --- | --- |
| TXT | `图片名.txt` | 逗号分隔标签；描述模板则保存整段文字 |
| JSON（完整格式） | `图片名.json` | `fixed`、`character`、`ai_output` 等分组字段 |
| JSON（简化格式） | `图片名.json` | `count`、`appearance`、`tags`、`environment`、`nl` 等顶层字段 |

输出格式决定本次写入的文件，不再由已有标签的扩展名决定。另一种格式的旧文件保留，完成后可撤销本次写入。“跳过已有标签”检查所选输出文件是否已有内容，空文件仍会打标。

训练读取哪份标签由数据集的“标签格式”决定。Auto 在同名 JSON 和 TXT 都存在时优先读取 JSON；需要使用新生成的 TXT 时，将数据集标签格式设为 TXT。打标不会自动修改训练配置。

### 视觉大模型打标

“视觉大模型”把每张图片发给支持图片输入的模型，按回复写入标签。接口需兼容 OpenAI Chat Completions。服务、密钥、模型和请求参数在“设置 → 打标”中设置，保存在服务端，打标面板显示当前使用的服务和模型：

- **服务**：OpenAI、Google Gemini、OpenRouter、SiliconFlow（硅基流动）、阿里云百炼、DeepSeek 使用固定地址；Ollama、LM Studio 和自定义服务填写地址。请求由训练服务器发出，同一台机器上的服务填 `127.0.0.1`，其余地址按“设置 → 系统设置 → 网络代理”访问。
- **API 密钥**：保存在服务端的 `secrets.json`，保存后不再显示，也不写入操作记录。云端服务需要密钥才能开始。
- **模型**：点“获取模型列表”后从列表选择，也可手动输入模型名。模型列表只在点击时读取；自定义和本地服务需先填写地址。

输出格式与提示词模板分开选择：TXT 可生成标签或自然语言描述；JSON 可生成分类标签与描述，或只更新描述字段。输出选项始终对应明确的文件扩展名，不再使用“TXT / JSON 描述字段”这类混合选项。

触发词写在 TXT 最前面，JSON 写入 `meta.trigger`。排除标签不会写入。提示词中的 `{trigger}` 换成触发词，没有触发词时含它的行会删去。内置提示词只读；选择“自定义”后可以编辑，并将内容另存为当前浏览器中的模板。

请求参数包括温度、最大输出长度、图片长边（默认 1024 px，发送前按白底合成透明区域并转为 JPEG）、`detail` 参数、并发数、请求间隔、超时和重试次数。限速（HTTP 429）、服务错误（5xx）和超时按次数重试；密钥被拒绝（401 / 403）或地址、模型不存在（404）时立即停止。模型拒绝回答、回复为空或格式不符的图片记为失败，其余图片照常写入，完成后可查看失败原因。

服务的拒答字段、内容过滤状态、空回复和已识别的拒绝文本会记为失败，不覆盖原标签；分类回复中的描述字段也单独检查。空 TXT 或没有对应内容的 JSON 不会因为文件存在就被跳过。

运行中点“停止”后不再发送新的请求，已回复的图片仍会写入。完成后可一次撤销本次写入的全部标签。

### 辅助打标

“辅助打标”先取得每张图片的参考标签，再连同图片一起发给视觉大模型修正：

- **以已有标签为参考修正**（默认）：已有标签的图片使用自己的标签，其余图片先用 Tagger 模型打标。
- **跳过已有标签的图片**：只处理没有标签的图片。
- **忽略已有标签，重新打标**：所有图片都先用 Tagger 模型打标。

提示词中的 `{tags}` 换成参考标签；提示词不含 `{tags}` 时，参考标签附在末尾。分类写入时，Tagger 识别出的角色名写入 JSON 的角色字段（文件已有角色时保留原值），其余标签交给模型分组。

辅助打标的内置提示词沿用 PurinBox 原文，并按输出格式提供：

| 输出格式 | 提示词模板 | 行为 |
| --- | --- | --- |
| TXT | 标签调优 | 修正参考标签，输出逗号分隔的标签 |
| TXT | 详细自然语言打标 | 参考标签与图片，输出整段描述 |
| 两种 JSON | 标签调优 + 自然语言描述 | 修正、分类标签，并填写 `nl` |
| 两种 JSON | 归类字段 + 补描述 | 保留全部参考标签，只重新分组并补 `nl` |
| 两种 JSON | 仅补自然语言描述 | 保留标签，只更新 `nl` |

分类写入按 `COUNT:`、`APPEARANCE:`、`TAGS:`、`ENVIRONMENT:`、`NL:` 回复段解析，再写成选定的 JSON 结构。“归类字段 + 补描述”由程序保证标签集合不变：丢弃新增标签，遗漏的参考标签放入 `tags`。

内置模板只读，“保存为模板”不可点击；选择“自定义”后可以修改、保存、删除。自定义模板继承当前模板的回复类型，并记录适用的输出格式。模板保存在当前浏览器。

### 模型与运行环境

打标模型和检测模型可在对应面板中下载，也可在“设置 → 打标”统一下载和删除。下载来源在同一页选择 Hugging Face 或魔搭社区；没有魔搭社区副本的模型从 Hugging Face 下载。下载固定到已核对的版本，逐个文件校验大小和 SHA-256，Tagger 模型保存到模型目录的 `tagger/<系列>/<版本>/`（如 `tagger/wd/eva02-large-v3/`），遮罩检测模型保存到 `mask/<类型>/<版本>/`。旧版本下载在 `vision/<模型 ID>/` 的模型会自动移到新位置。

运行需要 ONNX Runtime，在“设置 → 运行环境 → 打标与遮罩”安装，装好后下次运行即生效，不需要重启服务。“云端版本”按“软件下载源”中的 Python 依赖包来源查询，与安装时使用的来源相同。NVIDIA 显卡使用 GPU 版并选择空闲显存最多的一张；训练占满显存时可改用 CPU。其他平台使用 CPU 版。模型在独立进程中运行，结束后释放内存。

## 标签编辑

左侧图片栏顶部的搜索框按文件名或标签筛选，输入后即时生效，旁边是刷新按钮；下方“全部 / 空标 / 已标”按标签状态筛选（有标签错误时另有“错误”），数量为整个目录；底部显示图片数量和翻页，每页 30 张。

逐图编辑支持 TXT 和结构化 JSON。JSON 编辑保留原字段分类及未知元数据，保存前检查文件版本，避免覆盖并发修改。字段格式及缓存规则见 [JSON 标签](JSON_CAPTIONS.md)。

打开一个数据集后，“批量编辑标签”为选中图片添加或移除标签，直接写入，不能撤销；打标和自动遮罩写入后可一次撤销。逐图保存标签也没有撤销记录。

## 遮罩

训练遮罩使用灰度 PNG：白色区域权重为 1，黑色为 0，灰色按比例加权。开启“遮罩加权训练”后生效，该设置位于训练参数的“数据与分桶 → 增强与遮罩”。

优先使用独立的 `.mask.png`；没有独立遮罩时读取图片透明信息；两者均无时使用全白权重。全不透明 Alpha 等价于全白遮罩。

遮罩与图片采用相同的缩放、裁切和翻转。在完整画面或原生尺寸模式中，遮罩尺寸必须与 EXIF 校正后的原图一致。图片仍完整输入模型，遮罩控制损失计算区域。

## 正则数据集

“正则数据集”向版本的 `reg/` 添加正则图，“图片来源”可选：

- **本地底模生成**：使用本版本训练参数中的底模，不加载 LoRA。“提示词来源”可手动填写类别提示词，也可“按训练图片标签逐张生成”，每张训练图片按自己的标签生成一张，“排除标签”中的标签从提示词中去掉。
- **Danbooru、Gelbooru、e621、Rule34**：“收集正则图”只下载站点标记为全年龄的图片，保留站点标签并去重，已收集过的图片不再下载。默认“按训练标签自动匹配”，按训练标签的占比检索，优先挑选宽高比和尺寸接近训练图片的；排除标签和触发词不参与检索，带排除标签的图片不会下载。也可改为手动输入检索标签。

每批最多 200 张，完成后自动加入正则集；已有的正则图可在“导入已有正则图”中导入。正则图不参与自动验证集划分。

版本内 `reg/` 目录作为正则来源，外部来源需明确设置用途。正则图与训练图的出现比例由图片数量、重复次数和分辨率展开共同决定；正则权重进一步缩放对应样本的损失。

## 追加图片与标签编辑

打开一个数据集后，“添加图片”会把文件加入当前目录，沿用该数据集的重复次数和标签格式。支持图片、同名 TXT／JSON 标签、遮罩、文件夹和 ZIP；文件夹或 ZIP 的单层外包装会移除，内部子目录保留。同名且内容相同的文件会跳过，内容不同则提示冲突，不覆盖已有文件。

标签编辑采用左侧图片列表、中间图片预览与标签、右侧标签统计的布局。图片列表底部可翻页，上一张／下一张可连续跨页切换。列宽和预览高度可拖动分隔条调整。

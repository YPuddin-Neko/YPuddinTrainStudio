# 存储与备份

## 源码与运行数据

源码目录包含启动脚本、`ypuddin/` 后端、`frontend/` 前端和 `docs/` 文档。平台基础环境默认位于源码目录的 `environment/`，前端构建输出到 `frontend/dist/`。

默认运行数据目录为 `studio_data/`：

```text
studio_data/
├── studio.db
├── settings.json
├── secrets.json
├── project/<项目 ID>/v<N>/
│   ├── config.json
│   ├── traindata/
│   ├── reg/
│   ├── cache/
│   ├── pipeline/
│   ├── samples/<任务 ID>/
│   ├── output/<任务 ID>/
│   └── jobs/<任务 ID>/
│       └── resume/
├── models/
├── runs/
├── presets/
├── cache/
├── thumbs/
├── network/
└── environment/
```

| 路径 | 内容 |
| --- | --- |
| `studio.db` | 项目、版本、任务、模型登记与产物记录 |
| `settings.json` | 路径、网络、服务、界面、打标、软件下载源和缩略图设置 |
| `secrets.json` | 模型下载的访问令牌、图站凭据和视觉大模型 API 密钥 |
| `network/` | 代理密码 |
| `project/<项目 ID>/v<N>/` | 当前版本的配置、数据、缓存和训练结果 |
| `traindata/`、`reg/` | 训练图片与正则图片，以及同名标签、遮罩 |
| `pipeline/` | 打标、自动遮罩、涂抹等数据处理的操作记录与撤销备份 |
| `samples/<任务 ID>/` | 训练预览图 |
| `output/<任务 ID>/` | 只放训练产物：训练权重或全量微调的模型 |
| `jobs/<任务 ID>/` | 任务配置、控制台日志、训练事件和控制文件；恢复点在其中的 `resume/` |
| `models/` | 默认模型下载和扫描位置；`models/tagger/<系列>/<版本>/` 存放打标模型，`models/mask/<类型>/<版本>/` 存放遮罩检测模型 |
| `runs/` | 未绑定项目的任务输出 |
| `presets/` | 参数预设 |
| `cache/`、`thumbs/` | 图片索引、共享编码缓存和缩略图 |
| `environment/` | 界面创建的 PyTorch 环境、安装器数据和服务控制文件 |

缓存准备和模型测试没有训练产物，文件都在 `jobs/<任务 ID>/`。

旧项目可能仍位于 `projects/<项目 ID>/versions/`。更新程序保留旧布局。更新后首次启动时，默认产物目录中旧任务的记录和恢复点移入 `jobs/<任务 ID>/`，已保存的路径同步改写。

## 路径设置

模型、缓存、输出和基础环境目录可在设置中指定。默认项目输出按项目、版本和任务分开存放；自定义输出目录采用相同的层级分隔。

上传及导入图片会创建版本内副本。直接引用外部数据来源时，逐图编辑的标签和遮罩以及“批量编辑标签”直接写入外部文件；打标、自动遮罩和“涂抹与遮罩”编辑需先“复制为可处理的新版本”。

数据目录的更换需要手动迁移：停止服务，将原数据目录完整复制到目标位置，再使用新路径启动。“数据根目录”也可在“设置 → 存储路径”修改，重启服务后启用，原有文件同样需要手动复制。更改设置不自动搬迁模型、项目或已有任务产物。相对路径按服务工作目录解析，跨机器部署宜使用绝对路径。

## 空间占用

“设置 → 存储路径”下方的“空间占用”只统计本软件自己的文件：训练器（程序文件和运行环境）、项目、模型权重和其他数据各占多少，下方按大小列出各项目版本。数据根目录以外只计入本软件写入或登记的文件，例如任务的产物、恢复点、采样图和日志目录，以及已登记的模型；与其他软件共用的文件夹里的其他文件不计入。统计结果保留 5 分钟，点刷新按钮可立即重新统计。

## 编码缓存

训练前的图像编码（VAE）和文本编码保存在版本的 `cache/` 中；训练参数的“缓存目录”可以指定其他位置。

```text
cache/
├── latents/<图片名>_<宽>x<高>.safetensors
├── text/<图片名>.safetensors
├── text/_prompts.safetensors
├── index.sqlite
└── fingerprints/
```

每张图片一个文件，以图片文件名命名；图像编码按分桶尺寸各存一个文件。水平翻转、换用其他底模或裁切方式得到的编码存在同一个文件里，互不覆盖；一个文件存满后先删除最早的编码。不同文件夹中同名但内容不同的图片，名称后附加内容哈希的前 8 位。采样提示词和空标注的文本编码存放在 `_prompts.safetensors`。`index.sqlite` 记录图片的尺寸和内容哈希，`fingerprints/` 记录模型文件的指纹。

旧版本按哈希分成子文件夹存放的缓存无法沿用，下次训练时自动删除并重新编码。

## 备份

停止服务后备份以下内容：

- `studio.db`、`settings.json` 和凭据文件。
- `project/` 或旧布局 `projects/`，包含图片、标签、遮罩和完整训练状态。
- `presets/`、自定义的训练产物、恢复点、采样图和日志目录，以及外部引用的数据集。
- 无法重新获取的模型权重。

凭据文件以明文保存，应限制读取权限，并从公开归档中排除。

编码缓存、索引和缩略图可以重建，但重建需要时间。仅保留导出的 LoRA / LoKr 权重无法恢复原任务的优化器、步数和随机状态。删除 Python 环境会导致后续重新安装依赖。

## 默认保存目录

“设置 → 存储路径”可分别设置训练产物、恢复点、采样图和日志的默认根目录。选择“默认目录”时，恢复点在 `jobs/<任务 ID>/resume/`，日志在 `jobs/<任务 ID>/`，采样图在 `samples/<任务 ID>/`。页面会显示完整默认路径，其中的项目、版本和任务部分在创建任务时自动填写；自定义根目录下也按项目、版本和任务 ID 分开保存。

修改默认目录只影响之后创建的任务，不移动旧文件。暂停、失败后的恢复与任务日志继续使用任务创建时记录的目录。

路径参数留空时，“浏览”从该功能的默认目录打开；已填写路径时从所填位置打开。恢复点是包含 `state.json` 的目录，按保存时间和步数命名，如 `state-20260929-143012-step000100`；按轮、暂停、停止和手动保存的恢复点末尾另加 `-epoch0002`、`-paused`、`-stopped`、`-manual`，旧恢复点保留原名。完整续训应选择这个目录。

## 缩略图缓存

“设置 → 系统设置 → 缩略图缓存”显示缓存占用，可手动清理或修改最大占用。默认上限为 1 GB，最低可设为 0.1 GB，保存后立即生效，超过上限时清理较久未使用的缩略图。此操作仅处理默认 `thumbs/` 和当前自定义缓存目录中的界面缩略图，不删除原图、标签或训练编码缓存；再次浏览时会重新生成。

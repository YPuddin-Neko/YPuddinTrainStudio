# 训练器测试完成度与剩余问题报告

日期：2026-09-17。产品源码基线：`3d79e7a4c827ef7196ec419a76926e69b523f393`。

本报告优先回答：**冻结文本编码器，只训练主模型的 LoRA／LoKr，以及分桶和海光多 GPU 是否已经可靠验收。** 依据本地保存的正式报告、配置说明和最新回归记录核对；本次仅整理证据，没有重新连接海光或执行新的 GPU 训练。旧节点是否仍可用不作推断。

## 结论

Anima／SDXL 的主模型 LoKr 已有海光单卡、双卡正式训练与严格续训通过记录；Anima 原生尺寸双卡 LoKr 也通过了对应用例。最新分桶完成本地回归。

**不能据此宣布最新版所有主模型 LoRA 训练均已验收。** 当前优先缺口是：Anima／SDXL 标准 LoRA 的双卡正式矩阵尚未补齐、新版分桶未做正式模型海光复验，以及 SDXL 150 token 的主模型 LoKr 严格续训仍有未解决差异。

界面中的“LoRA”是训练方式总称；算法选项中的 `lora` 与 `lokr` 是不同实现。本报告不把它们的验收结果互相替代。“尚未验收”不等于确认不能运行，“能训练和保存”也不等于严格续训通过。

| SDXL 225 token 主模型 LoKr | 对应用例通过 | 同批单卡用例，2100 个张量严格一致；不代表 150 token 被修复，也不代表所有双卡长标签组合已测 |

正式通过的主要标准是：连续训练 8 步，与第 4 步保存完整状态、退出进程、冷恢复至第 8 步比较。权重、优化器、调度器、随机数、数据位置／进度及预览必须严格一致，不以“误差很小”放行。这是短程正确性检查，不是长期画质或收敛验收。

SDXL 默认是 **75 个正文 token**，另可选 **150、225**，不是固定 150，也不是 150 个汉字。长文本分块送入两套 CLIP 后拼接条件，不扩大 CLIP 本身的单块位置编码。150 失败与 225 通过必须分别保留，尚无证据证明仅仅是“长度 150 本身有错”。

文本编码器训练按用户要求排后，未将其问题混入“仅训练主模型”的失败结论：

- Anima 单卡文本 LoRA：旧实机严格续训未通过，392／392 个张量不同；新版计算策略本地验证完成，海光复验未完成。
- SDXL 单卡主模型＋文本 LoRA：旧实机严格续训未通过，1930 个张量中 1918 个不同；新版实机复验未完成。
- Krea2 单卡文本 LoRA：504 个张量、状态和重载检查通过对应 `1406e35` 用例。
- 文本适配器的海光多卡、其他模型／算法组合没有完整验收覆盖。

Anima 全参原 `1e-5` 小数据配方的预览泛白已做独立诊断；`1e-6` 固定配方通过双卡严格续训且预览有正常可见色彩。不能据此证明任何学习率都合适，也不能把全参配方现象说成主模型 LoRA 整体无法训练。

## 三、明确的功能边界，不应写成“只是没测”

1. **LoRA／LoKr 多卡目前走 DDP，每卡保留完整底模。** 它能分担数据计算，不会把两张 64 GiB 卡自动变成能容纳单份 128 GiB 底模的显存。当前 FSDP 分片路径只支持主模型全量微调，尚不支持 LoRA／LoKr 适配器分片训练。这与用户希望“大模型放进两张卡”的用途直接相关。
2. 当前 DDP 的块换出、编译、梯度检查点等组合有明确限制；检测到两张卡不代表所有单卡省显存功能可以同时启用。
3. 原生模式仍受像素预算限制，超预算可以缩小或报错；已完成的 Native 验收不是任意原图分辨率都原样训练，也没有 NaViT 序列打包。
4. 单卡、DDP、FSDP 和不同卡数的完整状态不能随意互换后声称精确续训。换训练方式可以从导出权重开始新任务，但那不恢复原优化器和数据位置。
5. 新桶策略改变归组／顺序，旧桶完整状态会被策略身份校验拒绝；需要原版本严格续训，或用导出权重开始新任务。原生路径和相同实际几何的图片缓存不因此统一失效。

## 五、下一轮优先验收及完成标准

按以下顺序，冻结文本编码器，不以新增文本训练功能分散这轮目标：

1. **Anima／SDXL 标准 LoRA：单卡基线＋海光双卡 DDP。** 验证只有目标适配器更新、文本编码器冻结、两卡确实参与、权重导出及原生重载、冷进程严格续训、预览一致。
2. **修复并复验 SDXL 150 token 主模型续训差异。** 75／150／225 使用同一固定新版本分别验收，检查尾块文本确实参与条件；不能通过删除长标签、放宽误差或跳过预览将失败改为通过。
3. **把新版分桶接入同一实机矩阵。** 覆盖 crop／pad、不放大小图、来源分辨率、缓存开关和 mask 的代表性组合；比较数据分布、实际尺寸、状态保存及恢复后的批次顺序。LoRA 和 LoKr 分别记录。
4. **补产品队列闭环。** 两个任务分卡、训练与模型测试并行、暂停／恢复／取消、重启后占用释放，确认只控制所属任务，不影响另一张卡。

短程正确性通过后，长期稳定性、画质和速度另做代表性数据集对照。没有固定训练步数、数据集、模型和质量判据的“训练效果正常”不作为验收结论。

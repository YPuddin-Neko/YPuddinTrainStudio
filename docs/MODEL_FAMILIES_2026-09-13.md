# SDXL 与 FLUX.2 Klein

当前可选模型为 Anima、Krea 2、SDXL、FLUX.2 Klein。FLUX.1 和 FLUX.2 dev 已停用，原来的项目、配置、模型文件和训练结果会保留，不会自动改成 Klein。

## 如何选择

| 模型 | 需要准备什么 | 选择时注意 |
| --- | --- | --- |
| SDXL | 完整 SDXL checkpoint，或 UNet、双 CLIP、VAE | 默认下载光辉 Illustrious v0.1。第三方模型可手动选择；按模型说明选 ε 或 v 预测。 |
| Klein base 4B | Klein 4B 基础版、Qwen3 文本编码器完整目录、FLUX.2 VAE | 优先用来尝试较小显存设备；能否运行仍取决于权重精度和换出设置。 |
| Klein base 9B | Klein 9B 基础版、对应 Qwen3 文本编码器完整目录、FLUX.2 VAE | 编码器也更大，不能仅凭减小训练分辨率就保证 16 GB 显卡可用。 |

Klein 的蒸馏版与基础版不是同一种训练配置。两者权重尺寸可能相同，所以单文件无法可靠自动区分；请选择发布说明明确标注的 **base**。目录元数据充分时可以自动识别，明确为蒸馏版的权重会拒绝。当前不提供蒸馏版、KV 或图像编辑模型训练。

添加模型时按文件结构检查类型，旧 dev 不会被登记成 Klein。新项目也不会继续使用已登记的旧 dev 默认权重。旧配置仍可查看，但需要创建受支持模型的配置后再训练。

## 缓存与显存

Klein 准备训练时，先缓存图片和文本；编码器用完卸载，然后才读取训练主模型的实际权重。缓存是存下编码结果，下次有效时直接复用，不是一直把编码器留在显存中。

文本编码阶段仍需要把整个文本编码器放到设备上。训练时可使用主模型块换出与激活重算，减少显存占用，但会增加 CPU 内存需求或训练耗时。Krea2 的当前流程与它不完全相同，见 [Krea2 显存说明](KREA2_MEMORY.md)。

训练中的预览会临时加载 VAE 解码图片，此时主模型和优化器仍有占用；预览完成后再次卸载 VAE。不能把训练阶段的显存当成预览峰值。

## 采样与验证

Klein 基础版默认预览 50 步、CFG 4；没有额外的模型引导值参数。SDXL 当前支持 Euler / Heun 与自己的 DDPM 日程，不能直接使用 Flow 模型的时间偏移和采样组合。

缩小的真实网络已覆盖缓存、训练、预览、保存回读和 LoRA/LoKr 导出数值对照。完整权重的图像质量、速度和显存需要逐模型实测；小网络测试不能代替它们。初次接入的详细证据保存在 历史验收记录（本地验收记录），其中 FLUX.1/dev 的通过结果只代表停用前的版本。

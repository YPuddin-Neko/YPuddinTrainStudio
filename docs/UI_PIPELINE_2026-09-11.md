# v0.5.0 数据准备、原生分辨率与交互验收

本轮针对实际使用反馈继续改造；v0.4 的功能清单和旧截图不能代替本轮验收。参考项目为本地 AnimaLoraStudio 0.27.0，参考源码保持独立、未修改。除了源码调用链，还在隔离环境运行其网页，实际查看了项目、筛选、预处理裁剪和标签生成步骤。

## 参数页面和监控

- 高级参数组改为顺序排列，组内按可用宽度分列。组与组不再共用网格行高，避免短组被旁边长组撑出大块空白。
- 概率类字段以百分比编辑，后端仍保存 0～1；数值框、单位与滑条有各自位置。时间步、学习率、步数/比例混合参数保留各自单位，不能统一乘 100。
- 监控顺序为 CPU、内存、GPU、硬盘；各指标使用固定宽度，上下两行共用中心线。数字与单位作为整体居中，缺失横杠不保留空单位宽度。GPU 单独显示占用、显存占用率、功率和温度，组间有明确间隔。驱动未提供的值显示为空缺符号，不能编造读数。
- 任务完成后所有阶段均显示完成，避免最后一步仍显示正在收尾。

## 数据准备流程

项目版本的训练数据页包含「导入 → 检查与筛选 → 预处理 → 标签与遮罩 → 训练准备」。步骤可以回退和跳转，预处理和提前缓存都可跳过；修改素材后，旧检查和准备结果会标记过期。

检查会真正解码图片，识别损坏文件、完全重复内容、缺少标签、小尺寸和遮罩问题。重复副本选择优先保留带遮罩、带标签的图片，用稳定路径顺序处理平局。界面区分图像文件数与可解码图片数。

排除、裁剪、缩放和批量标签修改都有持久化操作记录与原文件备份。裁剪/缩放同时处理独立遮罩；标签编辑支持填写缺失、追加去重、移除和完整替换，支持 `{filename}`、`{folder}` 模板。撤销时若文件已经被外部修改，拒绝直接覆盖并给出冲突。失败、取消与重启恢复沿操作日志回滚未完整发布的修改。

训练准备调用真实的配置计划与缓存任务，刷新页面后可以继续查看进度。准备任务移交到训练队列期间持有同一版本锁，避免释放编辑锁和入队之间出现并发修改窗口。

可视裁剪支持自由、原图和常用比例；拖动画面中的选区和四角调整，以原图像素坐标提交。实际验收从 101×79 的图片拖出 57×57 选区，遮罩与原遮罩相同坐标的像素完全相等，随后撤销恢复原文件。恢复操作也会核对备份哈希，备份损坏时拒绝覆盖当前素材。

## 本地标注与模型来源

「标签与遮罩」接通 WD14 自动标注：选择图片、本地模型与 CPU/CUDA 设备，设置常规/角色阈值和触发词，支持只填缺失、追加去重、替换原标签。两个阈值并排显示；例如界面 12.5% 对应后端 0.125。图片在训练机本地推理，不上传服务；推理结束退出进程释放模型。可取消加载或推理，未完成的草稿不写入标签，成功写入后可按操作记录恢复。

设置 → 模型权重提供固定版本的 `wd-swinv2-tagger-v3` 下载，分别校验 ONNX 和标签 CSV 的 SHA256。设置 → 运行环境提供 ONNX Runtime CPU 运行库安装和实际版本检测；安装后按提示重启。CUDA 推理要求另行配置兼容的 GPU 运行库，界面只在驱动提供对应执行器时允许选择。环境维护与本地打标互斥。

底模下载支持 Hugging Face 和魔搭 ModelScope。令牌在模型权重页「下载令牌」中分别保存或清除，API 只显示是否已配置。自定义根路径和已有组件路径仍可使用；镜像请求不附带凭证，跨域跳转剥离认证头。令牌保存在运行数据目录的 `secrets.json`，属于本机明文凭证，源码包排除此文件。

实际下载了官方固定版本 WD14 两个文件，共 467,769,446 字节并校验哈希，真实 CPU 推理生成标签。本轮浏览器把缺失的 `img_001.txt` 填为 `native_flow, no humans, gradient background, ...`，随后进入训练准备并完成真实缓存任务。另有独立真实推理测试覆盖保留已有标签、追加去重、完整替换、取消及逐字节撤销。魔搭验证包括官方小文件下载和目录 API/尺寸，未下载完整底模，未实测私有仓库令牌授权。

## 文件归属

新版本沿用 v0.4 的独立目录：

```text
studio_data/projects/<project-id>/versions/<version-id>/
  config.json                 本版本训练参数
  datasets/<dataset-id-name>/  图片、同名 .txt 和 .mask.png
  cache/                      本版本可重建缓存
  pipeline/<operation-id>/    数据操作日志、原文件备份和撤销依据
  runs/<job-id>/              一次训练的配置快照、日志、断点和权重
    samples/                  该次训练的采样图
```

具体配置文件名以版本目录接口返回为准。新导入的素材复制到本版本；兼容旧项目的外部来源先复制到独立版本后再进行可写操作。旧项目迁移不移动已有文件或改写历史任务快照。修改另一个版本的标签、遮罩和图片不会改变当前版本。

## 原生分辨率

详细行为见 [原生分辨率说明](native-resolution.md)。实现使用受像素预算约束的同尺寸前向分组，一个逻辑批次可以含不同尺寸；梯度按实际图片数归一化，保留尾批。尺寸对齐前不无条件重采样，不放大小图，不填充图片；超过预算可等比缩小或报错。

这条路径使用已有模型和损失接口，不额外要求 NaViT/xFormers，不强制 latent 预缓存，支持 Mask 与在线 VAE 编码。模型本身的已有约束仍然生效。不能据此宣称速度超过序列打包实现，也不能把像素预算当成显存不会溢出的保证。

原生模式的独立遮罩必须与方向校正后的原图尺寸一致，预检会把不匹配问题定位到遮罩设置，避免训练中静默偏移。EXIF 方向进入真实几何探测，原生裁剪与传统分桶使用不同 latent 缓存标识。

## 实际验证记录

本轮独立浏览器项目中，实际导入包含 1 张损坏图、1 组重复图、缺失标签和 3 张遮罩的测试目录，操作检查、排除、恢复、再次排除、裁剪和标签编辑。101×79 图片与遮罩裁剪为 64×64 后，撤销恢复到原始尺寸，并且两个文件与导入前逐字节一致。标签模板写入实际 `.txt`，撤销后恢复缺失状态。

从真实网页配置并启动 Toy/MPS 原生训练：8 张图片、4 种尺寸、逻辑批大小 3、梯度累积 2、3 轮共 6 次更新。启用 Mask、在线 VAE 编码，实际处理 24 个样本。完成后 4 张 64×64 采样和 4 份权重均通过 HTTP 下载逐字节核对；权重包含原生模式及预算元数据。

第二个版本复制完整数据后追加独立标签，原版本未改变；将像素预算降为 8,192 后，6 张图按计划缩小，仍完成 6 次更新。两次任务共 8 张采样、8 份权重均通过 HTTP 下载与磁盘文件逐字节核对。

最终回归：后端 **483 通过 / 3 CUDA 跳过**，前端 **176 通过**；TypeScript、生产构建、ESLint、Python lint、35 个修改 Python 文件的格式检查以及 Git 差异检查通过。完整机器记录见 [v0.5.0.json](validation/v0.5.0.json)。

编译版浏览器实测 1440/1000/390 宽度：高级参数组间距为 12px，窄屏无文档横向溢出；1000px 顶栏标签与整体读数中心误差小于 0.01px。另用独立 CSS 压力数据验证缺失、零和三位数读数；压力数值不是实际硬件读数。明暗主题、设置抽屉上下文、百分比输入、服务重启后的事件恢复均已复查。

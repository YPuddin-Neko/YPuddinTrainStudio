# 模型测试

模型测试使用已保存的权重生成 XYZ 对比图，用于比较权重版本、LoRA 强度与采样参数。任务独立进入队列，不继续训练或修改原训练配置。

## 基础设置

从主导航打开“模型测试”，选择来源训练任务、采样底模、训练权重、提示词和运行显卡。

“沿用本次训练底模”读取来源任务的底模。训练权重可以选来源版本里每个训练任务保存的权重；底模或训练方式不同的任务不会列出。不勾选训练权重时只用底模生成。比较 LoRA 强度时需先选定一个训练权重。来源是全量微调任务时，训练权重一栏变为“全量模型检查点”，必须选择已保存的检查点，不提供“采样底模”和 LoRA 强度。

## 对比轴

| 轴 | 布局 | 示例 |
| --- | --- | --- |
| X | 每个值一列 | 强度 `0, 0.5, 1` |
| Y | 每个值一行 | 步数 `4, 8` |
| Z | 每个值一页 | 随机种子 `42, 43` |

该示例生成 3 列、2 行、2 页，共 12 张图片。未放到轴上的设置采用固定参数，同一参数不能同时占用两个轴。

数值以逗号分隔；权重、采样器和调度器使用选项列表。勾选多个训练权重时，它们放到一个空闲的轴上逐个对比。每个轴的取值数量不限，一次最多 1000 张；图片很多时，可下载的整页网格会缩小每张小图，原图不受影响。

比较权重或采样参数时可固定随机种子，避免同时改变初始噪声。

## Krea 2 Turbo

Krea 2 Raw 训练得到的 LoRA / LoKr 可搭配 Turbo 采样底模。Turbo 默认使用 8 步、Euler 和 CFG 0，手动设置及对比轴优先。

CFG 为 0 时只计算正向提示词。Turbo 的 CFG 公式为 `正向 + CFG × (正向 − 负向)`；Raw 保持其原有采样方式。

## 结果与取消

生成时按钮显示“生成中”和已完成的张数，鼠标移到按钮上变为“取消生成”。进度条按当前图片的采样步数前进；加载模型和处理提示词时显示为等待动画，排队时显示等待的原因。

右侧的对比记录按时间倒序列出每次测试的缩略图，排队和生成中的记录可以直接取消；窄屏时记录排成一行，放在结果上方。任务进入全局队列后可离开页面，回来后在记录里重新打开。小图支持放大及原图下载，Z 轴以分页显示，各页网格可单独下载。

取消生成会停止任务，保留已经生成的图片。模型测试不支持暂停或断点续跑；重新生成会创建新任务。归档版本可查看历史记录，不创建新任务。

## 模型常驻与释放显存

LoRA / LoKr 等适配器的测试完成或取消后，生成进程保留已加载的底模（放在内存中，出图时移到显卡）。下一次使用同一底模、同一显存设置和同一显卡的测试直接开始，不再重新加载。文本编码器每次按新的提示词加载，用完即卸载。

保留的底模在以下情况自动卸载：

- 队列要开始训练、缓存等其他任务，或开始环境安装、AI 正则图生成；
- 闲置 15 分钟；
- 下一次测试换了底模、显存设置或显卡。

页面右上角的“释放显存”可随时手动卸载，测试正在生成时不可用。测试失败后生成进程直接退出，不保留底模。全量微调模型的测试每次加载各自导出的模型，完成后也不保留。

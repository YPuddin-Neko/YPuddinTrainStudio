# 参数布局与数据工作区验收 · 2026-09-13

源码版本仍为 0.5.9。本记录接续 `FULL_ACCEPTANCE_2026-09-13.md`，单独描述这轮布局、导入进度和标签工作区修改；前一份报告的训练与测试计数属于此前验收。

## 参数页面

- 工作区最大宽度 1240px。宽屏表单与数据分布侧栏分别占 944px / 280px，中间 16px；标题与模型族放在同一行，搜索、高级开关、预设和配置工具按相邻操作排列。
- 基于实际工作区宽度重排，避免只看整个浏览器宽度而忽略侧边栏。窄窗口中数据分布移到表单后方；更窄时工具栏换行、参数改为单列。
- 文本编码器与 VAE 在空间允许时并排。异步加载版本后才挂载的工具栏也开始测量；换行通过 ResizeObserver 更新吸顶与底部留白高度。
- 数据入口分为导入、标签编辑、涂抹与遮罩，并携带当前版本和可确定的数据源，避免进入错误目录。

实际浏览器检查：2108×1097、1440×900、1004×773、375×812。2108 宽下工作区实测 1240px、工具栏 47px；375 宽下工具栏换行到 89px、表单单列。页面没有整体横向溢出，吸顶工具栏未覆盖页签；提示浮层在视口内，点击空白处关闭。各页签、LoKr 与优化器控件均实际打开检查。

## 数据工作区

- 侧边栏收起按钮固定在左下角；1004×773 下展开与收起位置均为 x=12、y=729、40×36px。
- 数据源下拉框与搜索区域有独立收缩和换行规则；遮罩页面只显示图片与遮罩操作。中文按钮标签保持横向排列。
- 标签编辑独立成页：缩略图、图片及标签编辑器、整个目录的标签频次。宽屏统计位于右侧，窄屏下移；支持标签词条和文本编辑、JSON 自然语言描述、保存、未保存切图/离页保护、频次筛选与标签状态筛选。
- 统计读取已索引且仍存在的图片及其当前同名标签文件；按图片去重计数，JSON 的自然语言描述与其他元数据不计入标签词频。新加入的图片仍需要正常索引。
- 相同图片哈希通过相对路径区分编辑目标。JSON 保存保留未知字段；不可解析的 JSON 不会被静默改写为 TXT。
- “质量检查”改为“数据检查”，展开说明具体检查项目：图片解码与小图、标签缺失/格式、遮罩可读性与尺寸、内容完全相同的图片、目录存在性。不把检查描述成审美或语义质量评分。
- 检查与缓存使用共用进度组件。操作记录默认收起，位于工作区最底部；只读检查明确标注未修改文件，可恢复的修改才提供恢复操作。
- “训练准备”改为“训练缓存（可选）”。图片缓存是 VAE 编码后的 latent，文本缓存取决于文本编码设置；正常启动训练会自动准备缓存，提前生成不是必经步骤。
- 主滚动区、侧栏、弹层和内部列表采用共用深浅主题滚动条，并支持减少动态效果偏好。

标签交互实际参考了本机 PurinBox 的 `src/pages/TagManagerPage.tsx`：缩略图选图、大图预览、标签词条/自然语言编辑，以及目录频次点击筛选。工作区按本项目容器宽度重新实现；原有 Dataset 编辑器的标签序列化和离页保护继续复用。

## 导入进度

浏览器上传与训练电脑目录导入共用后端进度跟踪。接收、解压、校验、复制、登记按实际处理阶段报告；未知总量显示不定进度，已知量展示真实字节或文件计数。速度、已用时间、剩余时间不再用定时假进度模拟。进度读取独立于长操作数据库锁；请求失败、轮询结束和卸载会停止轮询。

局域网 HTTP 环境可能没有 `crypto.randomUUID`，现在可使用 `getRandomValues`；两者都不可用时仍可完成主导入，并提供等待状态，进度能力不会阻断上传。

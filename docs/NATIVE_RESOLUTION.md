# 原生分辨率

原生模式按每张图的尺寸组织训练，不使用公共宽高比桶。实际训练画布仍需满足模型对齐要求、面积上限和最长边上限。

## 尺寸上限

两个上限同时生效，并包含对齐产生的补边。

| 参数 | 填写方式 |
| --- | --- |
| 图像面积上限 | 选择自动计算，或自定义等效正方形边长。1024 对应 1024×1024，约 105 万像素 |
| 最长边上限 | 任意一边允许的最大像素长度，默认 4096 |
| 超出尺寸上限时 | 等比缩小到上限内，或报错并停止 |

自动模式根据实际参与训练的图片计算，包含正则图片，不包含已移出训练或划入验证集的图片。每张图片先按最长边上限、模型对齐和图片适配方式计算画布尺寸，再取最大的画布面积作为上限。这个值是容纳当前训练集所需的最小面积预算；不按平均尺寸缩小大图，也不放大小图。修改数据集或相关尺寸设置后，参数页会重新计算；已经开始的训练沿用启动时确定的预算。

自定义面积上限为 1024、最长边为 4096 时，2048×2048 图片仍会因面积超限缩小。保留该图片的原始尺寸，可将面积上限设为 2048，最长边保持 4096。

`dataset.native_max_pixels_mode` 可设为 `auto` 或 `custom`；旧配置未填写时沿用自定义上限。自定义输入为边长，`dataset.native_max_pixels` 保存对应面积。例如输入 2048，对应配置值为 4194304。切换到自动模式会保留自定义值，便于切回。

面积上限同时约束一次计算中图片画布的总像素数。自动计算依据图片尺寸，不估算显存容量；如果大图占用显存过多，可改用较小的自定义上限。

## 对齐与适配

Anima、Krea 2、Klein 的对齐单位为 16，SDXL 为 8。以 1001×777 原图、对齐单位 16、预算充足为例：

| 图片适配方式 | 结果 |
| --- | --- |
| 保留完整画面 | 不缩放，补边到 1008×784 |
| 裁切填满 | 不缩放，按所选位置裁到 992×768；默认居中 |

“裁切保留位置”提供九个方向。选择上中会保留顶部、从下方裁掉多余部分；选择右上则保留右侧和顶部。图片与遮罩使用相同位置，翻转在裁切之后进行。修改裁切位置后，下次训练会重建受影响的图像缓存；从完整状态恢复原任务时需保持原设置。

超过尺寸限制时，按“超出尺寸上限时”的选择缩小或报错。完整画面模式可通过补边处理短边小于对齐单位的图片；裁切模式拒绝此类尺寸。

图片与遮罩采用相同的变换。补边仍参与模型前向计算，纯补边区域的训练损失权重为零。

## 批次与计算次数

一个逻辑批次可以包含不同尺寸。程序在批次内按相同尺寸与面积预算分组，每组单独计算，再按图片数累积梯度。

例如 `[768×512, 768×512, 512×768]`，面积预算为 786432 时，前两张可共同计算，第三张单独计算；三个样本在平均损失中的权重相同。

参数页的“每轮计算次数”表示每轮按尺寸分组运行模型的次数。梯度累积决定参数更新次数，两者不等价。原生模式不按分辨率列表复制样本，来源重复次数仍生效。

## 多卡与恢复

多卡先分配逻辑批次，再在卡内分组。不同卡的分组数不一致时，分组较少的卡补充零权重计算以保持通信次序；该过程增加计算开销，不增加真实样本数。

精确恢复需要相同的数据、几何模式、卡数、批大小和梯度累积。更换原生、裁切或补边模式后，应创建新训练任务。其他限制见 [多卡训练](MULTI_GPU.md)。

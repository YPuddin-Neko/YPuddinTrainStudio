# 参数工作台、全量微调与环境隔离验收

这次把参数页改成固定工具栏、独立滚动表单和固定启动栏。配置流程可以直接跳到模型、数据、优化器、显存、采样与保存；窄窗口使用流程下拉框，分桶面板可打开和返回。常用/全部参数使用分段按钮。TOML 导入改为弹窗，导入中的请求不会在弹窗关闭后覆盖用户后续编辑，错误显示在弹窗内。

项目概览增加训练/正则集切换、数据源与子目录筛选、分辨率与长宽比分布、标签统计、图片预览和训练产物。统计读取当前版本的完整索引，不用预览的少量图片代替总量。

## 训练能力

- 明确区分适配器与全量微调。全量模式可选择主模型、文本编码器或两者；文本编码器训练使用在线编码，不能读缓存冒充训练。
- 全量产物保存为原生组件目录，下载为 `.model.zip`；不显示适配器转换或无意义的 Rank/Alpha。
- 全量 XYZ 必须绑定已保存的模型检查点。切换检查点会加载对应主模型与文本编码器并重新编码，不能静默退回训练前的底模。
- 对不兼容的精度、卸载及缓存组合进行前后端检查。完整规则和产物格式见 [训练参数说明](TRAINING_PARAMETERS.md)。

## 环境与设置

Windows CUDA、Linux CUDA、macOS MPS 和各平台 CPU 有独立入口、venv、安装计划和 Torch 切换记录。旧 `venv` 保留；普通旧入口仍能启动原部署。详见 [环境切换与服务重启](ENVIRONMENT_LIFECYCLE_2026-09-14.md)。

设置提供手动重启、独立准备 Torch 版本、关闭安装结果后的持久化记录。模型目录移到下载区顶部，下载任务显示实际速度和剩余时间；停传时不会继续显示旧速度。推荐列表移除了 Anima Preview。

海光 BWGPU/DTK 与单任务多卡训练仍待硬件接入。用户提供的后续依赖入口是 [DTK 安装包目录](https://download.sourcefind.cn:65024/4/main/)，本轮没有从该入口下载安装，也不把 NVIDIA/MPS 测试结果算作 DTK 验证。

## 已实现

设置新增独立“软件下载源”页签。Python 依赖包默认使用中国科学技术大学，可切换清华大学、阿里云或 PyPI 官方。PyTorch 可选择国内镜像自动顺序、阿里云、上海交通大学或官方源。CUDA / CPU 使用专用安装包源，macOS 使用 Python 包源。

设置保存到当前数据目录的 settings.json。后续的 PyTorch 环境安装、扩展依赖解析以及启动器安装读取同一设置。启动命令显式指定 --index 或 --mirror 时，以命令行为准。无保存设置的首次安装保持原有国内镜像优先策略。

可关闭自动回退；日志记录实际地址。各个来源顺序尝试，不混用多个 PyPI 索引。取消安装立即终止，不触发下一个来源。CUDA 环境约束包含 +cu 版本后缀，防止普通依赖解析替换为 CPU 安装包。海光本地厂商 wheel 路径保持独立；模型权重和 FlashAttention 社区发布文件仍使用各自下载来源。

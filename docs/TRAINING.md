# 训练配置

## 训练流程

训练配置按项目版本保存。任务入队时保存配置快照，按显卡资源调度，随后扫描数据、生成尺寸与批次计划、准备缺少的缓存、加载训练组件并进入训练循环。

参数页提供字段说明、取值限制和训练计划。计划包含样本数、批次、尺寸及显存估算；模型加载、编码和采样阶段仍可能产生额外内存峰值。

参数更改后自动保存到当前版本。“另存为新预设”保存可复用的参数组合。“参数检查”列出未识别字段、当前条件下不使用的字段和取值错误；勾选后可移除字段，取值错误需要修正。

## 训练方式

| 方式 | 更新内容 | 保存格式 |
| --- | --- | --- |
| 适配器训练 | 底模保持冻结，训练附加权重 | `.safetensors` |
| 全量微调 | 更新所选主模型或文本编码器的权重 | `.model` 目录 |

可选训练对象取决于模型。训练文本编码器时必须每步编码标签，不能使用固定文本缓存；VAE 保持冻结。全量微调使用 FP32 可训练参数，可配合受支持的混合精度，不使用 FP8 底模或分块换出。

只有一个文本编码器的模型（Anima、Krea 2、FLUX.2）导出时，文本编码器层以 `lora_te_` 开头，与 ComfyUI 和 sd-scripts 读取的名称一致；SDXL 的两个文本编码器分别使用 `lora_te1_` 和 `lora_te2_`。此前导出的 `lora_te1_` 文件仍可用于采样、模型测试和继续训练；在产物页“转换格式”或用 `ypuddin convert` 转换后，文件改用新名称，ComfyUI 才会加载其中的文本编码器部分。

### 训练算法

| 算法 | 结构 | 导出格式 |
| --- | --- | --- |
| LoRA | 两个低秩矩阵相乘 | LoRA |
| LoKr | 两个小矩阵的 Kronecker 积，参数通常最少 | LoKr |
| LoHa | 两组低秩矩阵逐元素相乘 | LoHa |
| OrthoLoRA | 在底模权重的主要方向上做正交旋转和缩放 | 同秩的普通 LoRA |
| T-LoRA | 噪声越大可用的秩越少，减轻小数据集过拟合 | 普通 LoRA；正交初始化时秩为设定值的两倍 |
| LyCORIS Full | 直接训练所选层的完整权重，不做低秩拆分 | LyCORIS 差值文件 |

T-LoRA 和 LyCORIS Full 不能与 DoRA 同时使用；开启 DoRA 时，训练对象规则里改用这两种算法的层不启用 DoRA，其余 LoRA、LoHa、LoKr、OrthoLoRA 层照常启用。T-LoRA 只能分开计算，不能合并权重。OrthoLoRA 和正交初始化的 T-LoRA 导出的是普通 LoRA，无法还原训练参数，继续训练需要使用完整恢复点。LyCORIS Full 没有 Rank 和 Alpha，文件与所选层的权重一样大，学习率需要像全量微调一样单独设置。

### LoKr Full

“LoKr 参数形式”设为 Full 时，两个 Kronecker 因子使用完整矩阵，不再继续低秩拆分，仍然是 LoKr，与训练算法中的 LyCORIS Full 不同。Rank 和 Alpha 不参与该形式的设置，Factor 仍决定矩阵分解方式。

“训练层范围”决定哪些模型层添加适配器。“全部线性层”扩大覆盖范围，与 LoKr Full 是独立设置。全量微调则直接更新底模权重。

## 轮次与批量

| 参数 | 含义 |
| --- | --- |
| 重复次数 | 同一来源的图片每轮出现次数 |
| 轮次 | 按数据计划完整遍历训练项的次数 |
| 每卡批大小 | 每张卡一个逻辑批次的图片数 |
| 梯度累积 | 累积多少批梯度后更新参数 |
| 最大步数 | 参数更新次数上限 |

完整批次下，每次更新的有效批量为 `每卡批大小 × 梯度累积 × 数据并行卡数`。尾批、分桶、验证集划分和多分辨率展开会影响总步数。

## 分辨率与分桶

分辨率可填写一个或多个正整数，例如 `1024` 或 `1024, 1536`，支持逗号或空格分隔。

分桶模式中的 1024 表示目标面积约为 1024²，候选宽高由面积容差、宽高比和步长生成。每张图片在每个基准分辨率下各产生一个训练项，再应用来源重复次数。右侧分桶布局按基准分辨率分组。

| 图像适配方式 | 处理 |
| --- | --- |
| 保留完整画面 | 等比缩放后复制边缘颜色补齐；纯补边区域不计直接训练损失 |
| 裁切 | 等比缩放后裁切到桶尺寸 |

新建网页配置默认保留完整画面。缺少 `image_fit` 的旧配置沿用裁切行为。图片原文件不会被训练尺寸转换覆盖。选择裁切时，可用“裁切保留位置”指定九个方向；上中保留顶部，从下方裁去多余内容。

原生模式按图片本身尺寸分组，受面积与最长边上限约束，具体设置见 [原生分辨率](NATIVE_RESOLUTION.md)。

## 缓存

- **图像缓存**：保存 VAE 编码结果，减少后续训练的重复编码。
- **文本缓存**：保存标签及采样提示词的编码结果，可在完成后卸载冻结的文本编码器。
- **每步编码**：训练中重新编码当前标签，支持持续变化的文本条件。

Anima 冻结文本编码器时默认每步编码，也可使用缓存；其他模型的默认文字模式按模型配置选择。文本编码器参与训练时使用每步编码。

缓存方式在“数据与分桶 → 数据读取与缓存”设置。启动训练时自动生成缺少的缓存并复用已有有效结果。提前生成缓存只改变准备时间，不减少首次所需的编码计算。

图片缓存身份包含图像内容、几何处理和 VAE；文本缓存身份包含最终文本及编码器、分词器。修改图片、标签或相关编码设置会重建对应缓存。遮罩独立读取，不写入图像特征缓存。

## 精度与显存

| 设置 | 作用 |
| --- | --- |
| 模型加载精度 | 读取模型时使用的精度；默认按权重及平台选择 |
| 底模存储精度 | 冻结权重的驻留精度；部分平台支持运行时 FP8 量化 |
| 混合精度 | 前向、反向计算时的自动混合精度 |
| 可训练参数精度 | LoRA / LoKr 参数的存储精度，默认 FP32 |
| 导出精度 | 保存推理权重时的精度 |

运行时 FP8 只转换受支持的冻结线性层，不修改原始模型文件。前向按计算精度使用权重；该设置不等于原生 FP8 矩阵计算。Apple MPS 和 CPU 路径使用 FP32，FP16 动态梯度缩放仅开放单卡。

梯度检查点通过反向时重算中间结果减少显存。分块换出把部分冻结主模型块保存在主机内存中，按需传输，增加内存与传输开销。多卡和全量微调不支持分块换出；SDXL 单卡也不提供该选项。编译与分块换出不能同时开启。

## 优化器与调度

参数表根据优化器显示有效选项。优化器自行管理的学习率或调度参数由程序约束，切换算法后需检查剩余参数。

所需扩展包未安装的优化器和注意力后端在下拉框中置灰，并标注“未安装”。AdamW 8-bit 和 Lion 8-bit 依赖 bitsandbytes，只能在 NVIDIA 或海光显卡上使用，可在“设置 → 运行环境 → LoRA 环境”安装。

时间步采样控制训练中的噪声分布；学习率调度控制参数更新幅度；预览采样器和采样调度器用于生成图像。SDXL 采用 DDPM，Anima、Krea 2、Klein 采用 Flow，相关噪声参数按模型区分。

## 保存与恢复

推理权重与完整训练状态分别保存：

- 推理权重用于出图、合并或初始化新训练。
- 完整状态另含优化器、调度器、进度、数据位置、随机数状态及启用的 EMA，用于继续原任务。

开启“定期保存恢复点”后，可设置保存次数和单位：`100 Step` 每 100 次参数更新保存，`2 Epoch` 每完成 2 轮保存。默认 `100 Step`，关闭“定期保存恢复点”开关可停用；轮中达到最大步数不算完成一轮。暂停会在参数更新边界另存状态并释放显存；重启或异常退出后可从最近一次成功保存的状态继续，尚未保存的步数需要重跑。

恢复会检查模型、数据、几何配置、精度和分布式设置。修改图片、标签、遮罩或关键配置后，旧状态可能被拒绝；更换训练方式时应从保存的权重开始新任务。

训练已完成、希望继续优化时，切换高级模式，在“适配器 → 初始化与继续训练 → 继续训练的权重”选择上次导出的权重，并保持底模、算法和权重结构匹配；再设置本次新增的轮数或步数，按需调整学习率和数据。此方式重新初始化优化器和训练计数，不填写“恢复完整训练状态”。“重新训练”复用原配置，不会自动选取上次的最终权重。

“保存与恢复”中的“将训练参数写入 LoRA”默认关闭。开启后，普通和 EMA 权重会包含学习率、优化器、训练尺寸、步数等配方参数，可用 LoRA Metadata Viewer 查看。LoRA 和 LoKr 均支持；本机目录、图片标签、提示词和访问密钥不会写入。配方不含优化器状态，不能用于完整断点恢复。

## 训练日志

任务详情页的“日志”在训练进行时持续显示新输出；滚动到末尾时跟随最新内容，向上查看时停止跟随，可点击“回到最新”返回。每条记录分列显示时间、级别、来源和内容，异常堆栈与多行内容归入所属记录。筛选可只看警告和错误，搜索匹配内容和来源；更早的内容从日志顶部加载。

“日志与监控 → 日志级别”决定训练日志记录的详细程度，对之后启动的任务生效：

- Debug：新配置的默认值，额外记录设备与精度、各阶段耗时、数据分桶、优化器与调度器、恢复点保存和采样等细节。
- Info：只记录常规进度。
- Warning：只记录警告和错误。

调试记录在日志页默认隐藏，打开“调试日志”后显示。完整日志保存为任务日志目录中的 `run.log`，可在日志页下载。

## 配置文件示例

下例为单卡 Anima LoRA 配置。模型和数据路径需替换为本机路径。

```toml
[model]
family = "anima"
dit_path = "/models/anima.safetensors"
text_encoder_path = "/models/Qwen3-0.6B"
vae_path = "/models/qwen_image_vae.safetensors"

[dataset]
sources = [{ path = "/data/images", repeats = 1 }]
resolutions = [1024]
batch_size = 1
image_fit = "pad"

[adapter]
algo = "lora"
rank = 16
alpha = 16

[optimizer]
type = "adamw"
lr = 0.0001

[loop]
epochs = 10

[checkpoint]
output_dir = "/data/output"
save_every_epochs = 1
```

文件支持 TOML 和 JSON。命令行可通过 `ypuddin validate config.toml` 校验配置，再使用 `ypuddin plan config.toml` 检查数据与计划。命令列表见 [开发指南](DEVELOPMENT.md#命令行)。

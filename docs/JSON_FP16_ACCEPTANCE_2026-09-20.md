# Anima JSON 标签与 FP16 真机验收

本轮按用户指定范围，仅验证结构化 JSON 标签和 FP16 路径。长时间训练、高分辨率测试由用户进行，本轮没有启动这两类任务。硬件为 Windows 11、RTX 5070 Ti 16 GiB 单卡，独立测试环境 PyTorch 2.13.0+cu130。

## Anima JSON 标签

正式 Anima 2B，冻结文本编码器，LoRA／LoKr × 缓存／在线文本编码，共 4 组全部通过。缓存组同时缓存潜变量；在线组关闭潜变量缓存。每组连续训练 4 步，与第 2 步检查点由新进程恢复至第 4 步严格比较。

从已有测试数据复制 4 张图片到独立目录，创建两种支持的结构：嵌套 `tags` 分类格式与 `fixed`／`ai_output` 完整格式。原始图片、标签文件未修改。测试 JSON 在训练前后 SHA-256 一致。

| 检查项 | 缓存组（每种算法） | 在线组（每种算法） |
| --- | --- | --- |
| 标签丢弃实际触发 | 4 次样本读取 | 6 次样本读取 |
| 分类内部顺序实际改变 | 5 次 | 5 次 |
| 整段标签丢弃 | 2 次 | 2 次 |
| 固定前缀、自然语言描述 | 所有非空标签保持 | 所有非空标签保持 |
| 跨分类打乱 | 无 | 无 |
| 权重、优化器、RNG、进度与预览严格续训 | 通过 | 通过 |

增强记录来自同配置、同种子、同索引和轮次的确定性数据管线重放，未替换训练算子。固定前缀包括 trigger、quality、count、character、series、artist；appearance、tags、environment 各自在组内打乱与丢弃。整段标签丢弃按功能定义返回无条件文本，因此“固定字段保留”针对未整段丢弃的样本。文本缓存提供每图 4 个增强变体，训练从这些变体取样。

## FP16 修复

检查发现原训练器只有 autocast 与非有限梯度检查，没有动态梯度缩放。本次提交 `64f5d354a9dd50b54c2cc5c4ab21b6cad1e0532c`：

- CUDA FP16 混合计算启用 GradScaler，反向前缩放，梯度裁剪前还原。
- 梯度溢出时不更新参数、调度器或训练步数，清空梯度并降低 scale、重置增长计数。
- 正常更新后推进缩放器；检查点保存和恢复完整缩放器状态。
- 缺失或不匹配的缩放器状态不允许宣称精确恢复。旧 FP16 检查点可仅加载权重开始新训练。

本次 FP16 指混合计算，适配器参数为 FP32；底模文件未改写。当前动态缩放只开放单卡，FP16 可训练参数配置明确拒绝。多卡请使用 BF16／FP32；本轮没有海光或多卡 FP16 验收。

- Windows 缩放器测试 7 项通过、0 跳过，包括真实 CUDA 张量上的溢出跳步、裁剪前还原和冷恢复增长计数。溢出用例显式注入 Inf 梯度，不冒充正式模型自然发生的溢出。
- 本地缩放器与数值恢复策略集合：34 通过、3 项 CUDA 跳过；这 3 项已在 Windows 通过。
- 本地 Anima／SDXL 管线、检查点与缩放器集合：22 通过、3 项 CUDA 跳过。首次沙箱运行的多进程通信受限，中断本轮测试进程后授权重跑通过。
- Ruff 和 Git diff 检查通过。

## FP16 正式模型结果

| 模型 | LoRA | LoKr | 第 2→4 步实际更新张量（LoRA／LoKr） |
| --- | --- | --- | --- |
| Anima 2B | 严格通过 | 严格通过 | 448／672 |
| SDXL Illustrious XL | 严格通过 | 严格通过 | 1120／1680 |
| Krea2 Raw，已有 FP8 scaled 底模 | 严格通过 | 严格通过 | 280／420 |
| FLUX.2 Klein base 4B | 严格通过 | 严格通过 | 160／240 |

共 8 组，均以正式模型在 CUDA 上连续训练 4 步，对比第 2 步冷恢复后训练至第 4 步，训练权重、优化器、调度器、RNG、采样进度与预览 PNG 完全一致。分辨率预算 256，梯度累积 2，文本编码器冻结。Anima JSON 的另外 4 组也全部通过，共 12 个训练用例。

8 组 FP16 的 scale 均为 65536，增长计数从第 2 步的 2 恢复并推进至第 4 步的 4，与连续训练一致。这些短程模型任务没有自然发生溢出；降 scale、跳过更新和恢复增长的验收来自前述显式 Inf 注入 CUDA 测试，不混淆两种证据。

所有通过项均确认第 2→4 步权重确实更新。每个训练报告的 166 个源码文件哈希已核对：JSON 用例对应 `8d5f540`，FP16 用例对应 `64f5d35`。本轮最后检查没有遗留测试训练进程。

# XYZ 对比采样

XYZ 把不同参数生成的图片排在一起，方便挑选训练权重、LoRA 强度和采样设置。它使用已经保存的权重生成图片，不会继续训练或修改原来的训练配置。

## 从哪里打开

从主导航打开 **模型测试**，或进入项目版本的 **训练结果 → 模型测试**，然后选择一次训练任务。

先选“采样底模”和“训练权重”，再填写提示词。“沿用本次训练底模”使用这次训练记录中的模型；“只看底模（不加载 LoRA）”可以查看未加训练权重的效果。比较 LoRA 强度时，需要先选择保存过的训练权重。

## X、Y、Z 怎么填

| 位置 | 图片怎么排 | 示例 |
|---|---|---|
| X 轴 | 从左到右，每个值一列 | LoRA 强度：`0, 0.5, 1` |
| Y 轴，可选 | 从上到下，每个值一行 | 采样步数：`4, 8` |
| Z 轴，可选 | 每个值单独一页 | 随机种子：`42, 43` |

这个例子会生成 3 列 × 2 行 × 2 页，共 12 张。每张图片都会使用对应的三个轴值；其余设置来自“固定参数”。同一个参数不能同时放在两个轴上。也可以只填 X 轴，先做一排简单比较。

数值用逗号分隔；训练权重、采样器和调度器直接勾选。界面会显示总张数。每轴最多 12 个值，每次最多 64 张，同时还有总像素限制。

比较权重或参数时，先固定随机种子；需要看看不同初始噪声下的效果，再把种子放到一个轴上。权重比较只能选择当前来源训练任务保存的权重。

## Krea 2：Raw 训练，Turbo 出图

**训练用 Raw；Turbo 只用于采样。** 在“管理与下载模型”中准备标有“仅采样”的 Turbo，再回到这里把它选为“采样底模”，搭配 Raw 训练保存的 LoRA / LoKr。两者共用 Krea2 文本编码器和 Qwen-Image VAE。

选择 Turbo 后，固定参数会切为 **8 步、CFG 0**。首次比较可选 Euler，保持时间步偏移为默认。CFG 0 时不使用负面提示词；提高 CFG 后才会计算负面提示词分支。

如果某个轴已经选了“采样步数”或“CFG”，该轴的取值会覆盖对应固定参数。例如步数轴是 `4, 8, 12`，就会分别生成三个步数的图片。Raw 与 Turbo 是不同底模，换底模后效果也可能变化；Turbo 不能设为训练默认或用于继续训练。

## 生成后怎么看

点击“生成对比图”，任务会进入全局队列，等待空闲设备后逐张生成。可以离开页面，再从对比记录或队列回来查看。

点击小图可放大并下载原图；Z 轴用分页切换，每页网格可以单独下载。“复用参数”可以在原设置上继续调整并新建一次比较。

“取消生成”会停止这次任务，已保存的小图仍保留。XYZ 不支持训练式暂停和断点续跑；重新生成会新建一次任务。

更多 Turbo 模型说明见 [Krea 2 Turbo 用于采样](KREA2_TURBO.md)。

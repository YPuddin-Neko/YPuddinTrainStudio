# 工作区 UI 重设计与验收（2026-09-13）

本轮以 `9a4c05b` 为基线，重新整理项目入口、数据工作区、训练参数和共享界面尺度。参考同级 AnimaLoraStudio 源码中的项目概括、数据选择和任务组织方式，独立实现适合本项目版本隔离与 API 的交互；没有复制其实现，也没有改变训练算法或搬动用户数据。

## 设计与实际行为

### 项目入口与概览

- 项目列表提供卡片/列表切换、分类、搜索和排序，保留手动上传封面、裁切与既有归档流程。
- 打开项目默认进入概览。项目名称、版本与当前位置始终可见，侧边栏增加概览入口，收起按钮保持在左下方。
- 概览读取当前版本的真实图片、标签、遮罩、训练/正则数据量、模型配置与训练动态；缺少索引和读取失败不会冒充为零。
- 参数摘要合并后端默认配置并保留显式空值；“已配置”仅表示保存了配置，不表示模型文件或显卡训练已验证。
- 概览的数据、标签、遮罩、模型和结果链接直接进入对应工作区，不被之前记住的子页面覆盖。
- 无版本地址重定向到当前版本时保留查询参数、锚点和导航状态，避免结果列表和数据子步骤丢失。

### 数据导入、浏览、标签与遮罩

- 版本数据集采用紧凑图片卡片，每个目录最多请求三张缩略图，显示角色、重复次数、索引状态和数据量；不再把长目录名铺成整行空白。
- 导入前突出拖入区域和两个选择按钮。成功后收起已完成的大进度区及表单，显示结果、用时和目录链接，支持继续添加及收起。
- 从数据集详情可明确返回所属版本的数据集列表；刷新详情后仍可返回，后端归属优先于错误的来源查询参数。
- 图片目录选择与图片筛选分成两行。目录可搜索，目录切换后重置当前图片筛选/分页；标签状态、统计与编辑保留在独立标签工作区。
- 窄屏下缩略图带位于编辑器上方，筛选控件换行，文字不竖排；遮罩工作区不混入标签编辑控件。
- 操作记录保持在数据流水线底部。图片与遮罩实际写入、撤销恢复和未保存离开保护沿用已有实现。

### 训练参数与预设

- 按实际容器宽度分栏，普通控件使用可读的字号和约 38px 高度。宽屏限制整体内容宽度，窄屏不把表单挤在统计栏旁。
- 底模放在第一分区；主模型路径与登记模型选择并排，文本编码器和 VAE 并排，避免大屏上只占左侧或单一输入框过长。
- LoKr 按训练结构、参数规模、初始化与正则组织。Full 模式不显示无效 Rank/Alpha 输入；两列顶端对齐。
- 参数搜索覆盖所有分区及高级参数，有空结果恢复入口；校验错误可定位对应字段。工具栏和标签栏高度随实际换行更新。
- 预设使用紧凑选择栏；名称/模型与可展开说明置于参数上方，不保留巨大的侧边列表；用途说明收起时不会丢失内容。保留保存、复制和未保存离开保护。

### 共享布局与其他页面

- 统一中性背景、系统字体、标题/正文/辅助文字层级，调整侧边栏、按钮、表单、状态和原生进度条。
- 仪表盘、队列、训练监控和设置随容器宽度调整；移动宽度下运行指标变成两列，设置依赖的版本、状态与操作不再互相覆盖。
- 修复空权重页“查看训练任务”跳回同一空页的问题；结果列表翻页时保留已选任务的名称和筛选，失败状态可恢复。
- 设置关闭后返回原工作区；弹出层和既有过渡/减少动画偏好保持兼容。

这次完成的是界面组织、响应式布局与关联流程修复，不以单元测试替代所有实际设备上的验证。没有进行 Windows 原生浏览器、正式模型长时间训练、多卡通信、安装/升级或整套数据换盘验证；也未重新执行全部下载、删除等有外部副作用的操作。

目录比较与已确认缺口见 [存储目录与迁移边界审计](STORAGE_LAYOUT_AUDIT_2026-09-13.md)。当前启动器的 editable install 会生成受忽略的 `ypuddin.egg-info`；Anima 的标准脚本直接运行源码，不安装自身包。目录审计发现的整体迁移、部分删除残留与重试顺序问题未在本 UI 改动中修复，用户文件没有被迁移或清理。

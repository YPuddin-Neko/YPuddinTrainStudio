## 本轮发现与修复

1. **Anima 精度边界错误**：BF16/FP16 权重与 AdaLN 的 FP32 输入在错误的 autocast 边界相遇，首次正式训练失败。修正精度边界后，正式 xFormers/FlashAttention 训练与采样通过。
2. **缓存进度提前到 100%**：文本与 latent 缓存原先把待编码批次计作完成；改为实际命中或写入成功后计数，覆盖批量刷新、重复项和异常测试。
3. **文本模型加载过慢**：Anima Qwen3 改为 meta 构造与权重赋值，保留 RoPE 的 FP32 缓冲。Windows 正式权重、两个独立 CPU 进程对照：加载 **92.842→0.625 秒**，固定隐藏层输出逐元素相同；加载及一次前向的 RSS 峰值约 **2,889→1,479 MiB**。这是该加载阶段的收益。
4. **CPU 存储重复与分配浪费**：swap 改用直接写入、按 block/dtype 打包的 pinned 存储，Klein 512 冷缓存随后通过。Krea2 又发现 scale 视图持有旧文件映射，修复后正式 256/512 通过。缓存完成后卸载 TE/VAE、再物化 DiT，避免同时保留几套大模型。
5. **继续处理瞬时 RAM 峰值**：Krea2 768 在 `cd7ec8e`、8 swap 下仍因可用 RAM 瞬时跌至 2,635 MiB 而中止，训练 0 步；准备结束又恢复至 15,204 MiB，**不是 CUDA OOM**。条件 CUDA 预加载及空闲分配释放完成 CPU 回归后，`3cc0c8d` 的正式 768 冷缓存重测通过；XYZ 首次绑定也已修正，避免立即搬回 CPU 撤销预加载。该 XYZ 分支已通过正式 Raw→Turbo API 链路。
6. **队列估算造成永久等待**：Raw FP8 的计划原先按不适合该模型的体积累加，正式任务一直排队。改用真实冻结权重大小、换出 block 与缓存阶段估算后，正常队列调度完成 Raw 训练和 Turbo XYZ，没有绕过调度器。估算仍不是实测分配峰值。
7. **测试观测修正**：旧监控只数到 Windows venv launcher，4 MiB RSS 不能代表模型内存；后续改为进程树统计。另有一次外部负载突变，已核实无本轮遗留 worker，不能当作仅改变 swap 数的因果对照。上传后的索引等待和原生拖入类型断言也曾是测试脚本错误，原始失败均保留。

8. **XYZ 文件与引用关系**：拼图和单图下载使用各自的任务、图片文件名。已有 XYZ 引用的训练任务、被排队或运行中的 XYZ 使用的权重会阻止单独删除，并检查创建与删除并发时的引用有效性。
9. **侧栏入口统一**：系统设置移到左下角，主题与语言统一在设置的“界面与服务”中调整；展开时显示“收起侧边栏”文字，折叠时保留可访问名称。相关39项前端交互检查、lint和构建通过。

## LoKr full 兼容与 v4 加速

**LoKr full 文件兼容已验证；本机测试不支持把 v4 融合加速设为默认。** 官方 LyCORIS `4a6a333` 的实际 Kohya 加载器在 Windows CPU 读取产品导出的非零 full/factor8、full/factor16、正负可学习缩放，以及 alpha≠rank 的低秩文件；六种配置各测强度 1/0.65，12 项全过，最大输出误差 4.77×10⁻⁷。原有外部加载器单测也实际通过，没有跳过。验证使用的是 LyCORIS 自己的加载器。

加速在独立目录测试，没有更换 venv 的 Torch/NumPy，也没有修改训练默认。Triton Windows 3.6.0.post26 的真实前向/反向核已经成功编译并执行；小矩阵中 FP32 两种尺寸通过对照，BF16 factor8 的一个梯度未过固定容差。四组小矩阵的前反向墙钟时间均未提速。

## 如何查证，以及这些结果不能证明什么

原始 JSON、日志、配置快照、校验清单与测试生成图位于**源码仓库同级的项目父目录 `remote-testing`**，属于验收资料，不作为产品运行依赖或随源码打包。主要入口为 `remote-testing/FINAL_TEST_REPORT.md` 与 `remote-testing/windows-final-evidence/`；正式模型细分目录为 `anima-xyz-1024-loader`、`sdxl-checks`、`klein-checks`、`krea2-checks`、`krea-api-xyz-planned256` 与 `krea-raw-preview-raw28-planned`。早期注意力与恢复证据另见 `remote-testing/acceptance.json`、`extended-acceptance.json`、`resume-deterministic-comparison.json`。这些是文字位置说明，不是要求仓库读者打开不存在的外部链接。

本次证明的是所列硬件与配置的短程功能：加载、编码缓存、前反向、保存、采样及具体控制动作。2–10 步不能证明数小时稳定性、收敛或画质；4B 的通过不代表 9B 已实测；单卡不能证明 DDP；batch/rank 增大或其他程序占用 RAM/显存都可能改变结果。断电、驱动重启、磁盘写满及所有高级参数组合未穷举。融合加速专项的失败和超时均保留，默认模式数值对照失败也不会改写成通过。

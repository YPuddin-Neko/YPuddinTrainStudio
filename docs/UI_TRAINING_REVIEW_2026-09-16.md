## 显卡选择的最终行为

按最后一次要求保留“训练显卡数量”的数字输入，并放在批次大小前。顶部选择入口在自动模式下仅显示“自动”。

- 填 1 时指定显卡采用单选，换卡替换选择。
- 填 N 时可复选最多 N 张；未选够会提示并阻止启动，不能让界面数量和实际任务不一致。
- 增加数量会保留当前选择，提示补齐；减少数量保留前 N 张，并明确提示移除的卡号。
- 自动模式按填写数量分配空闲卡。指定占用中的卡会说明需排队；不存在或不可用的设备不能提交。
- 真实浏览器截获的模拟提交分别为：指定双卡 `gpu_devices=['cuda:1','cuda:0'] / gpu_count=2`、指定单卡 `['cuda:1'] / 1`、自动双卡 `[] / 2`。模型测试与队列既有选卡入口另做回归。

## SDXL 的 SNR 与 v 预测

核对确认原有 ε/v 预测已经贯通：训练目标、同一噪声调度、预览采样和导出均使用相应设置。不能因为未列出 SD1/SD2 的 `v2` 或 `clip_skip` 就判断 SDXL 的 v 预测未实现。

本轮补上真实 DDPM 损失计算与前端控制：

| 配置 | 生效条件与计算 |
| --- | --- |
| `objective.weighting=min_snr` + `objective.snr_gamma` | 默认关闭；选择后 Gamma 默认 5。ε 使用 `min(SNR, γ)/SNR`，v 使用 `min(SNR, γ)/(SNR+1)` |
| `objective.scale_v_pred_loss_like_noise_pred` | 仅 v 预测；可选按 `SNR/(SNR+1)` 缩放损失 |
| `objective.v_pred_like_loss` | 仅 ε 预测，默认 0；增加按 v 预测尺度换算的损失，不能与 v 预测同时启用 |
| `objective.debiased_estimation_loss` | ε 使用 `1/√SNR`，v 使用 `1/(SNR+1)`，默认关闭 |

SNR 来自 SDXL 实际离散噪声调度，不复用 Flow 的 `snr_like`。后三项保持 sd-scripts 的 SNR 上限 1000；可与 Min-SNR 按相同顺序叠加。损失仍使用原有遮罩归一化与逐样本权重，诊断返回未加权误差。零终点处理避免 Min-SNR 的 `0/0`；非法预测组合、非有限 Gamma 等会拒绝。

前端只显示对应模型的可用项；导入了不兼容非默认值时保留可关闭控件及说明，不把无法启动的值藏起来。切换模型或预测方式会清理不适用组合。新损失开关默认关闭时维持旧配置散列，避免新增默认字段影响旧完整状态的原配置认证。

对照代码：[sd-scripts 损失函数](https://github.com/kohya-ss/sd-scripts/blob/4e624302e0088e39933b31cbc71f24212e900f5f/library/custom_train_functions.py)、[参数约束](https://github.com/kohya-ss/sd-scripts/blob/4e624302e0088e39933b31cbc71f24212e900f5f/library/args.py)。这些是可选加权，不是 v 预测训练必需条件，也不承诺提升质量。

当前仍有明确范围差异：SDXL 标签编码采用 77 token 上限，尚无 sd-scripts 的 150/225 token 分块。本轮没有把高级参数列表宣称为与其他训练器完全等量。

## JSON、原生尺寸与配平

当前 Anima、SDXL、Krea2、Klein 均通过公共解析器将支持的 JSON 标签转换为文本后编码；不是任意 JSON 都兼容。模型能力字段驱动格式选项，后端训练预检、自动格式选择和数据检查共用判断。未知结构、解析失败、模型不支持等错误会展示具体标签文件和原始原因。标签编辑保留未知元数据，不改写本次输入数据。

Anima JSON 的固定信息及自然语言 `nl` 不打乱，`appearance`、`tags`、`environment` 只在各自组内打乱。TXT 的 `keep_tokens` 不套用于 JSON。无 dropout 的 36 个固定种子/角色字段用例与 ALS 输出一致；dropout 有明确差别：我们允许整组丢空，ALS 保留至少一个，因此不声称所有配置逐字相同。缓存模式从预生成的变体中选择，并非每步重新编码。

右侧新增简版训练集配平图，统计排除验证集和无效输入后的实际训练项。单尺寸为图片数 × 重复次数，多尺寸明确包含尺寸档数；正则集单列分组。占比计算包含正则项，且在多卡末批剔除之前，不冒充实际损失权重。

数据分布首次显示“正在计算”；重新计算保留上一份结果并标明正在更新。失败后保留旧结果、提供重试，同时清除可启动状态；旧请求不能覆盖更新后的配置。

原生尺寸和各训练器分桶的详细区别、静态尺寸实例及多卡边界见 [分桶源码对照报告](BUCKETING_COMPARISON_2026-09-16.md)。没有做同机吞吐或训练质量优劣承诺。

# 原生尺寸训练

原生尺寸模式按每张图自己的尺寸安排训练，不先套进公共的宽高比桶。是否裁切由“图像适配方式”决定，“原生”不等于所有像素都不变。

## 一张图会变成什么

以原图 **1001×777**、对齐单位 16、像素预算足够为例：

| 图像适配方式 | 实际处理 |
| --- | --- |
| 完整画面（`pad`） | 不缩放；居中放进 1008×784 的画布，复制边缘颜色补齐，纯补边部分不计训练误差 |
| 裁切（`crop`） | 从中心裁成 992×768；不缩放，但边缘少了一些像素 |

- 新建的网页项目默认 `pad`；缺少 `image_fit` 字段的旧 JSON／TOML 仍按 `crop` 读取。手写配置想保留完整画面，需要明确写 `dataset.image_fit = "pad"`。
- 对齐单位：Anima／Krea 2／Klein 为 16，SDXL 为 8。
- 图片、alpha 通道和独立的 `.mask.png` 使用相同的几何处理；完整画面和原生模式下，遮罩文件的尺寸必须与按 EXIF 方向校正后的原图一致。

## 两个尺寸上限怎么填

界面中的两个上限同时生效，包含对齐补边。它们都不表示显存容量：

| 设置 | 含义 |
| --- | --- |
| 图像面积上限 | 填正方形的边长。默认 `1024` 表示最多 1024×1024，约 105 万像素；横图、竖图仍保留各自比例 |
| 最长边上限 | 宽、高任意一边都不能超过这个值，默认 `4096` 像素 |
| 超限处理 | 默认等比缩小到预算以内；也可以选择直接报错，不会悄悄丢图 |
| 批大小 | 一个逻辑批次包含的图片数，可以有不同尺寸 |
| 梯度累积 | 几个逻辑批次后才更新一次参数；最后不完整的一组按实际图片数计算 |

例如面积上限填 **1024**、最长边填 **4096**，2048×2048 的图片仍会因面积超限缩到约 1024×1024。若想保留 2048×2048 原图，可以把面积上限改成 **2048**，最长边保持 **4096**；任意尺寸还要给对齐后的画布留出空间。上限越大，可能使用的显存越多。

界面填写的是边长，导出的配置 `dataset.native_max_pixels` 保存其平方，例如填 `2048` 会保存 `4194304`。这个面积也限制同一次计算中所有图片的总像素。

- `native + pad`：在预算内不放大、不缩放，画布向上对齐；超出预算才缩小。短边小于对齐单位的图可以靠补边容纳。
- `native + crop`：向下对齐并裁切，超出预算时先缩小；短边小于对齐单位时报错。

原生模式不使用分辨率列表、宽高比上限、桶步长和多分辨率复制，但来源的重复次数仍然有效。参数页的尺寸分布显示实际尺寸、缩小数量和计算次数；计算次数不等于参数更新次数。

## 不同尺寸如何一起训练

例如一个逻辑批次包含 `[768×512, 768×512, 512×768]`，预算为 786,432：前两张尺寸相同且总像素在预算内，一起计算；第三张单独计算。三张图各占三分之一的权重，不会因为第三张单独一组就被加重。每组反向传播后立即释放计算图。

这是按尺寸分组计算，没有把不同尺寸的 token 打包成一个序列（NaViT 式打包），所以不需要专门的变长注意力，遮罩、图片缓存和断点续训都照常可用。图片尺寸种类越多，前向次数越多，速度不一定比分桶快。

## 多卡

原生尺寸可以用于数据并行和显存分片，各自的限制不变，见 [多卡训练](multi-gpu.md)。

各卡先分到逻辑批次，再在卡内按尺寸和预算分组。如果某一轮 GPU 0 有三组、GPU 1 只有一组，GPU 1 会额外计算两次本卡最小的分组，**这两次的损失乘零、图片计数为零**，让每张卡以相同的次序参与前向、反向和通信，避免某张卡提前结束、其他卡一直等待。

- 补跑不增加图片的重复次数，也不改变真实图片的权重；损失和梯度按所有卡的真实图片总数归一。补跑仍然消耗计算时间和临时显存。
- 整轮逻辑批次不能被卡数整除时，略过最后不足一组的批次，每轮重新打乱；计划会列出首轮略过的训练项数。逻辑批次数少于卡数时拒绝开始。
- 计划中的 `forward_groups` 包含补跑的前向次数，`synchronization_groups` 单独列出其中的补跑次数，它们都不是参数更新次数。

## 成本与限制

- 补边仍会经过 VAE 并作为模型的上下文，不是免费的空间；有效区域权重只去掉了纯补边位置的训练误差。
- 像素预算不是显存上限，底模、文本编码器、优化器、注意力和预览都各自需要空间。
- 原生、裁切和完整画面使用不同的缓存；换模式后不能继续原来的精确断点，可以新建版本，从已有权重开始。
- 精确续训要求相同的卡数、每卡批大小、梯度累积和数据。

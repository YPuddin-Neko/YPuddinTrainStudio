## 改动

- 冻结底模的线性权重从不可分片的 buffer 转为不参与训练的参数，保持原 BF16／FP16／FP32 存储精度。
- 适配器独立分片并通过模块调用触发 FSDP 汇集和释放，避免冻结底模与 FP32 适配器在旧版 FSDP2 中混合归组。
- 保存原始适配器参数、优化器、每卡随机数和采样位置；恢复时校验训练类型及适配器配置。便携导出保持普通 safetensors 格式，不导出完整底模。
- 显存估算区分冻结权重与可训练参数，仅给后者计入梯度和优化器状态。
- 前端配置说明同步限制；不支持的 FP8、文本编码器训练、整层丢弃等配置明确拒绝，不静默降精度或退回 DDP。
